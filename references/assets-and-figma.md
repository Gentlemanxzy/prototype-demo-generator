# 资产与 Figma 复用规范

本文件约束 Figma 资产、用户独立素材和UI截图中视觉资源的识别、登记和复用。

## 资产优先级

1. Figma 中提取或导出的真实图片、logo、图标和装饰资产。
2. 用户单独提供的素材目录或资产包。
3. 用户明确指定可复用的背景图、logo、图标和截图。
4. UI图/原型图中可识别、可裁切或可近似复刻的视觉内容。
5. 页面模板或设计规范中的默认视觉方案。

有明确视觉资产时，不得使用纯 CSS 渐变、通用插画或泛化图形替代。

## 必须登记

产出 `analysis/assets-inventory.md`，记录：

- 资产名称。
- 类型：背景、logo、图标、地图、厂区鸟瞰图、模型、设备图、装饰线、截图等。
- 来源：Figma、用户素材目录、UI截图或估算。
- 使用页面和区域。
- 是否必须复用。
- 是否允许裁切、缩放、遮罩或调色。
- 是否已复制到本地项目。

## Figma 远程资产

Figma 返回的远程资产链接可能有时效性。用于最终项目时，应下载或复制到本地资产目录，并在 `analysis/assets-inventory.md` 记录来源和用途。

## 无独立资产时

如果只有UI截图，没有独立资产：

- 可将整张UI图/原型图或局部裁切作为背景/参考。
- 可近似复刻图标和装饰，但必须在资产清单和最终回复中说明。
- 不得声称已经复用了真实资产。
