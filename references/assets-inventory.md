# 资产清单规范

本文件用于指导 Agent 识别和复用用户提供的视觉资产。

## 输出位置

必须在生成项目内输出：

- `analysis/assets-inventory.md`

## 资产优先级

1. 用户单独提供的素材目录或资产包。
2. 用户明确指定可复用的背景图、logo、图标和截图。
3. 原型图中可识别、可裁切或可近似复刻的视觉内容。
4. 页面模板或设计规范中的默认视觉方案。

如果用户单独提供了资产包，不要优先从原型截图中裁切资产。

如果用户没有单独提供资产包，才从原型图中识别可复用视觉内容，并说明哪些内容只能近似复刻。

## 资产类型

常见资产类型：

- 厂区航拍背景图。
- 地图或管线图。
- logo。
- 顶部品牌标识。
- 左侧菜单图标。
- 场景点位图标。
- 设备图标。
- 摄像头或门禁图标。
- 装饰线条。
- 视频封面。
- 弹窗背景。

## 验收要求

- 关键背景图、logo、地图、厂区图和图标必须记录来源。
- 页面实现时必须使用清单中的关键资产。
- 无法复用或只能近似复刻的资产，必须在最终回复中说明。
