# 水厂数字孪生大屏设计规范

本文件根据 `Figma设计规范修正版.md` 整理，用于约束水厂演示系统的视觉设计和前端实现。

当用户提供原型图、页面截图或 Figma 导出图时，本文件只作为缺省设计规范。原型图中的布局、颜色、透明度、面板层级、字号、间距、阴影、发光和组件形态优先级更高；如果两者冲突，必须以原型图为准。

## 设计定位

水厂演示系统应呈现智慧水务数字孪生可视化平台的感觉，整体保持：

- 极暗背景
- 科技蓝
- 全息青
- 半透明毛玻璃面板
- 中央三维或仿三维主视觉
- 高密度数据看板
- 设备、告警、水质和运行状态清晰可读

视觉效果要服务于业务讲解，避免只做装饰性的科技风。

## 画布规范

业务大屏统一以 `1920 × 1080` 为设计基准。

前端适配规则：

- 按浏览器窗口等比缩放。
- 居中显示业务画布。
- 不改变业务元素之间的相对坐标。
- 不因窗口变化重新排列核心大屏模块。
- 安全边距左右 `24px`。
- 常用内容内边距使用 `16px / 24px`。

## 页面结构

默认采用以下大屏结构：

| 区域 | 尺寸 / 位置 | 用途 |
|---|---|---|
| 顶部导航 | `1920 × 64`，`x=0 y=0` | 平台名称、一级模块、天气、时间、用户信息 |
| 左侧收起导航 | `72 × 620`，`x=24 y=88` | 图标菜单，hover 显示文字 |
| 左侧数据面板 | `360px` 宽，`x=112 y=88` | 运行、水质、设备、能耗等摘要 |
| 中央主视觉 | 自适应填充中间区域 | 水厂总览、工艺流程、设备下沉或三维场景 |
| 右侧毛玻璃面板 | `380 × 932`，`x=1516 y=88` | 告警、设备、人员、视频、详情列表 |
| 底部状态栏 | `1920 × 36`，`x=0 y=1044` | 数据刷新、系统状态、平台标识 |

## 网格与间距

- 基础网格：`8px`
- 小间距：`8px`
- 常规间距：`16px`
- 模块间距：`12px / 16px / 24px`
- 面板内边距：`16px / 24px`
- 大区块间距：`32px`

所有组件尺寸、边距和圆角应尽量落在 8px 网格体系内。

## 字体规范

字体家族：

- 中文：`PingFang SC` / `Noto Sans SC` / `Microsoft YaHei`
- 英文与数字：`Roboto` / `Arial`

字号层级：

| 类型 | 字号 | 字重 | 用途 |
|---|---:|---|---|
| 页面主标题 | `24px` | Bold / Heavy | 顶部平台标题、模块标题 |
| 面板标题 | `16-20px` | Bold | 数据面板标题 |
| 关键数字 | `20-24px` | Medium / Bold | KPI、能耗、告警数量 |
| 正文 | `14-16px` | Regular / Medium | 表格、列表、普通信息 |
| 辅助说明 | `12px` | Regular | 单位、辅助标签 |

业务大屏正文最小建议 `14px`，重要指标数字不低于 `20px`，地图标签主文字不低于 `14px`。

## 核心组件

### 顶部导航 TopNav

- 高度 `64px`
- 背景 `rgba(18,29,44,0.92)`
- 底部分割线 `rgba(128,162,210,0.18)`
- 包含平台名称、一级模块、天气、时间、语言、用户信息
- 选中态使用蓝色渐变背景和底部 `2px` 高亮线


### 毛玻璃面板 GlassPanel

- 圆角 `8px`
- 内边距 `16px / 24px`
- 背景 `#30364A66`
- 描边 `1px rgba(158,193,255,0.18)`
- 模糊 `blur(12px)`
- 标题高度 `48px`

面板用于承载指标、列表、图表、告警、设备详情和水质趋势。

### 指标卡 MetricCard

内容包括指标名称、指标数值、单位、趋势或状态。

尺寸建议：

- 常规卡片：`171 × 72`
- 大型 KPI：`240 × 96`

状态要求：

- Normal：白色数字
- Highlight：全息青数字
- Warning：橙色数字或橙色描边
- Danger：红色数字或红色描边
- Empty：降低透明度，显示 `--`

### 场景标签 SceneLabel

用于水厂总览、工艺构筑物、设备热点、管线点位和告警点位。

状态要求：

- Default：深色半透明底 + 全息青描边
- Hover：背景提亮，描边增强
- Selected：品牌蓝渐变背景
- Warning：橙色描边或圆点
- Alarm：红色描边或闪烁
- Disabled：低透明度

点击下沉流程：

1. hover 标签时高亮。
2. 点击后进入 selected 状态。
3. 中央主视觉切换到对应构筑物、设备或工艺段详情。
4. 右侧面板同步切换为详情。
5. 提供“返回总览”按钮。

### 状态标签 StatusTag

| 状态 | 文案示例 | 颜色 |
|---|---|---|
| Success | 正常 / 在线 / 已处理 | `#70FFC3` |
| Info | 提示 / 巡检中 | `#3FC5FF` |
| Warning | 预警 / 待确认 | `#FFBD54` |
| Danger | 故障 / 离线 / 告警 | `#FF3A3A` |

### 告警列表 AlarmList

字段包括告警区域、告警类型、告警等级、告警时间和处理状态。

联动规则：

- 新告警出现时，中央场景点位同步闪烁。
- 点击告警行，中央场景定位到对应区域。
- 处理状态按 `New → Acknowledged → Handled` 变化。

### 视频弹窗 VideoModal

状态包括 Loading、Live、Offline、Error。弹窗应显示监控名称、位置、状态和关闭按钮。

## 场景规范

### 总览场景

必须包含水厂厂区或工艺总览主视觉、构筑物标签、处理水量 KPI、在线设备数、出水达标率、待处理告警和左右数据面板。

### 设备下沉场景

必须包含设备底图或仿三维设备场景、设备热点标签、设备状态列表、压力、流量、温度、频率、开度等运行参数，以及返回总览按钮。

### 告警联动场景

必须包含告警点位、告警列表、告警详情、地图或工艺点位定位和处置状态变化。

### 巡检场景

如用户要求巡检功能，应包含巡检路线、巡检人员位置、巡检任务列表和异常记录。

## 交互动效

| 交互 | 动效 |
|---|---|
| 导航切换 | `180ms ease-out`，背景渐变淡入 |
| 标签 hover | `120ms ease-out`，描边和发光增强 |
| 标签下沉 | `300ms ease-in-out`，场景淡出淡入 |
| 面板展开 / 收起 | `240ms ease-in-out` |
| 告警闪烁 | `1.2s infinite`，红色发光呼吸 |
| 数据刷新 | 数字轻微滚动或闪烁，不超过 `300ms` |

动效要克制，告警动效优先级最高，普通装饰光效不能抢占数据注意力。
