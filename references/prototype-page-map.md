# 原型页面映射规范

本文件用于指导 Agent 在实现前逐张登记原型图，避免遗漏页面或交互状态。

## 输出位置

必须在生成项目内输出：

- `analysis/prototype-page-map.md`

## 映射原则

- 每张原型图必须登记。
- 主页面和交互状态必须分开登记。
- 同一业务页面的展开态、选中态、弹窗态、详情态、轨迹态应归属到对应主页面。
- 不要把多张原型图混合成一个泛化页面。
- 不实现的原型图必须写明原因和影响。

## 状态类型

常用状态类型：

- `page`：主页面。
- `expanded`：展开态。
- `selected`：选中态。
- `modal`：弹窗态。
- `detail`：详情态。
- `drawer`：抽屉态。
- `trajectory`：轨迹查看态。
- `camera`：视频或监控态。
- `access-control`：门禁区域详情态。

## 验收要求

- 原型图总数应与输入目录一致。
- 已实现数量、状态数量和暂缓数量必须可追踪。
- 最终回复必须说明暂缓项。
