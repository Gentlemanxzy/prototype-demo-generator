# 视觉细节分析规范

本文件用于指导 Agent 在写代码前拆解原型图中的视觉细节，尤其是半透明面板、背景遮罩、边框、阴影、发光、字号、间距和组件状态。

视觉细节分析是原型驱动高保真生成的必做步骤。不要只写“半透明毛玻璃”“科技蓝面板”这类泛化描述。

## 输出位置

每个需要实现的主页面都应产出一个视觉细节分析文件：

- `analysis/pages/<page-id>-visual-details.md`

如果某张原型图是展开态、选中态、弹窗态、详情态或轨迹态，也应在对应主页面的视觉细节文件中登记状态差异。

## 最高优先级

原型图视觉细节优先于 `references/design-spec.md`。

当原型图与设计规范冲突时：

- 以原型图中的颜色、透明度、层级、字号、间距和组件形态为准。
- 设计规范只用于补充原型图未体现或无法判断的细节。
- 不得用默认 GlassPanel、TopNav、MetricCard 或通用色彩 token 覆盖原型中的真实样式。

## 必须分析的内容

### 背景层

记录：

- 背景图或主视觉来源。
- 背景整体亮度。
- 是否存在暗色遮罩。
- 遮罩颜色。
- 遮罩透明度。
- 是否存在顶部、底部、左右侧渐变压暗。
- 中央主视觉是否被面板覆盖或穿透可见。
- 背景与面板之间的层级关系。

### 顶部导航层

记录：

- 顶栏高度。
- 顶栏底色和透明度。
- 是否有渐变、描边、底部分割线或发光。
- 平台标题字体家族、字号、颜色、字重、行高和字间距。
- 一级导航字体家族、字号、颜色、字重、行高和字间距。
- 一级导航选中态样式。
- 时间、天气、用户状态等辅助信息样式。

### 面板层

分别记录左侧面板、右侧面板、底部面板、弹窗、标签和图表容器，不要把所有面板合并成一个统一样式。

每类面板记录：

- 位置和尺寸。
- 底色。
- 透明度。
- 是否使用 `backdrop-filter`。
- 模糊强度。
- 标题栏底色。
- 内容区底色。
- 描边颜色。
- 描边透明度。
- 是否存在渐变描边。
- 是否有内阴影。
- 是否有外阴影。
- 是否有发光。
- 角标、折角、装饰线或分割线。
- 圆角。
- 面板内边距。

### 半透明样式采样

必须单独记录半透明效果，不要只写“毛玻璃”。

```markdown
## 半透明样式采样

| 对象 | 底色 | 透明度 | 模糊 | 描边 | 阴影/发光 | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
| 顶部导航 |  |  |  |  |  |  |
| 左侧面板 |  |  |  |  |  |  |
| 右侧面板 |  |  |  |  |  |  |
| 弹窗 |  |  |  |  |  |  |
| 场景标签 |  |  |  |  |  |  |
```

如果无法精准取色，应估算为接近的 `rgba()`、hex 或 CSS 变量，并说明“估算”。

### 字体层

记录：

- 原型使用的字体家族或 Figma 字体。
- 顶部导航字体样式。
- 页面标题字号、颜色、字重。
- 面板标题字号、颜色、字重。
- 右侧卡片标题字号、颜色、字重。
- 右侧卡片指标数字字号、颜色、字重。
- 指标数字字号、颜色、字重。
- 单位字号和颜色。
- 列表、表格、标签、按钮、辅助说明的字号和行高。
- 文案密度：紧凑、常规或稀疏。
- 中文长文案是否需要省略、换行或缩小字号。

顶部导航和右侧卡片字体必须优先按原型图或 Figma 采样。无法精准判断时，应采用接近原型的偏小、紧凑字号，禁止使用通用大屏默认的大号导航或大号 KPI 数字。

### 点位坐标层

如果页面包含底图标签、地图点位、设备热点或工艺节点，记录：

- 点位名称。
- 原型坐标 `x/y`。
- 原型画布尺寸。
- 相对百分比 `left/top`。
- 所属背景图。
- 背景图显示方式：cover、contain、fill 或固定尺寸。
- 背景图实际显示偏移。
- 最终 CSS 坐标。
- 是否存在整体偏移风险。

### 间距和密度层

记录：

- 画布安全边距。
- 顶栏与主内容间距。
- 左右面板之间的模块间距。
- 面板内边距。
- 标题栏高度。
- 列表行高。
- 图表与标题、图例、数值之间的间距。
- 页面整体信息密度。

### 图表和数据组件层

记录：

- 图表类型。
- 图表背景是否透明。
- 坐标轴、网格线、图例、tooltip 的颜色和密度。
- 折线、柱状、环图、仪表盘的颜色。
- 指标卡数字、单位、趋势、状态的层级。
- 是否存在装饰性图形、进度条、环形占比或小图标。

### 状态层

记录：

- hover 态。
- 选中态。
- 展开态。
- 弹窗态。
- 告警态。
- 离线态。
- 轨迹态。
- 详情态。

状态原型中出现的视觉差异必须落到代码实现或交互触发中；如果暂缓，必须在 `analysis/prototype-page-map.md` 和最终回复中说明。
